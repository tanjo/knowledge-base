# 強制終了

## ショートカットキーで強制終了する

1. `Command + Option + Esc` キーを同時に押します。
2. 「強制終了」ダイアログが表示されます。
3. 強制終了したいアプリケーションを選択し、「強制終了」ボタンをクリックします。
4. 確認のダイアログが表示された場合は、「強制終了」を再度クリックして確定します。

## Appleメニューから強制終了する

1. 画面左上のAppleメニューをクリックします。
2. 「強制終了...」を選択します。
3. 強制終了したいアプリケーションを選択し、「強制終了」ボタンをクリックします。
4. 確認のダイアログが表示された場合は、「強制終了」を再度クリックして確定します。

## 注意

強制終了を行うと、アプリケーションで保存されていないデータは失われる可能性があります。必要に応じて、事前に作業内容を保存してください。
